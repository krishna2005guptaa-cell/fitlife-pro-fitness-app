# FitLife Pro - Complete Fitness App 💪

A comprehensive fitness tracking application built with React.js featuring workout tracking, nutrition planning, progress monitoring, and an extensive exercise library.

## 🌟 Features

### 🏠 Dashboard
- **BMI Calculator** - Track your Body Mass Index
- **Daily Calorie Recommendations** - Personalized based on your goals
- **Today's Workout Summary** - Quick overview of completed workouts
- **Quick Action Buttons** - Fast access to common tasks
- **Motivational Quotes** - Stay inspired!

### 🏋️ Workout Tracker
- **6 Workout Categories**: Cardio, Strength, Yoga, HIIT, Flexibility, Core
- **Customizable Duration** - 10 to 120 minutes
- **Intensity Levels** - Low, Medium, High
- **Calorie Burn Calculator** - Real-time calorie tracking
- **Workout History** - View your recent workouts
- **Exercise Suggestions** - Pre-defined exercises for each category

### 🍎 Nutrition Planner
- **Macro Tracking** - Calories, Protein, Carbs, Fats
- **Quick-Add Meals** - 6 pre-configured healthy meals
- **Custom Meal Logging** - Add your own meals
- **Daily Nutrition Summary** - Track your daily intake
- **Meal History** - View today's logged meals

### 📊 Progress Tracker
- **Weekly Statistics** - Workouts, minutes, calories burned
- **Weight Tracking** - Monitor weight changes
- **Body Fat Percentage** - Track body composition
- **Body Measurements** - Chest, Waist, Hips, Arms
- **Progress History** - View historical data
- **Achievement Badges** - Earn rewards for milestones

### 📚 Exercise Library
- **12+ Exercises** - Detailed descriptions
- **Filter by Category** - Strength, Cardio, Core
- **Search Functionality** - Find exercises quickly
- **Difficulty Levels** - Beginner, Intermediate, Advanced
- **Muscle Group Targeting** - Know what you're working

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/krishna2005guptaa-cell/fitlife-pro-fitness-app.git

# Navigate to project directory
cd fitlife-pro-fitness-app

# Install dependencies
npm install

# Start the development server
npm start
```

The app will open at `http://localhost:3000`
